# @stet-css/core

StetCSS: a markup-driven CSS engine where classes such as `fg:red:hover@sm` compile to CSS rules. This package is the public facade over the engine and the default preset.

## Getting started

Install the build integration for your framework and import `@stet-css/core` from your CSS entry. The [repository README](https://github.com/0Miles/StetCSS#readme) lists every integration package, and [`examples/`](https://github.com/0Miles/StetCSS/tree/main/examples) has a working project for each framework.

## Inspiration
Some of the core concepts and designs are inspired by these giants.
- The concept of enhanced syntax is inspired by [SASS](https://sass-lang.com/) and [TypeScript](https://www.typescriptlang.org/)
- The concept of Virtual CSS is inspired by the [Virtual DOM](https://reactjs.org/docs/faq-internals.html)
